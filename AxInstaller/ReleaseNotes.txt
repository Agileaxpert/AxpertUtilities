Enhancements:
1. Bulk install support for scripts and structures across multiple schemas
   Command:
   bulkinstall <product_version> <from_release> <to_release> <filename>.txt -web
   Example:
   bulkinstall 11.4 release5 release15 schemas_csv.txt -web

2. Support to upgrade any version to the 11.4 base version
   Command:
   prepare base <product_version>
   Example:
   prepare base 11.4

Upgrade to 11.4:
1. Execute:
   prepare base <product_version>
2. Apply patches using:
   install <product_version> <release_no>
   Example:
   prepare base 11.4
   install 11.4 release38

Important Note:
Version 11.4 must contain a basecode folder. The folder structure under basecode must match the release patches structure.
